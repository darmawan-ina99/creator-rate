# Creator Rate 🔢

Kalkulator harga endorse real-time untuk content creator Indonesia. Hitung rate card berdasarkan followers, views, engagement rate, platform, jenis konten, hak pakai, dan eksklusivitas.

## Demo
https://darmawan-ina99.github.io/creator-rate/

## Fitur
- 5 platform: TikTok, Instagram, YouTube, Facebook, X
- Harga berbasis CPM views + floor tier followers
- Multiplier engagement, niche, hak pakai, eksklusivitas, pengerjaan kilat
- Breakdown transparan + tips negosiasi dinamis
- Tombol salin rate card
- Responsif, bisa dipakai di HP/tablet/desktop

Dibangun sebagai single-page app tanpa dependency.
